# Pravaah Travels Project Rules

This is an existing React + Vite + TypeScript + Firebase travel booking platform.

## Never modify

- Firebase configuration
- Firestore collection names
- Authentication
- APIs
- Routing
- Business logic
- Existing data models

## UI Rules

- Match the Vitour Premium Travel template.
- Maintain consistent spacing.
- Maintain consistent typography.
- Use the existing green + orange design system.
- Never redesign unless requested.

## Development Rules

- Fix only the requested issue.
- Never modify unrelated files.
- Keep TypeScript strict.
- Preserve existing functionality.
- Run npm run lint before finishing.
- Explain every change.
